**在线访问：https://a2393439531.github.io/consult-quiz/**

## 功能

- 📚 11 个章节题库（共约 900 题），每题含参考答案与解析
- 📝 5 套综合模拟卷 / 专题卷（全真模拟、集训专题等）
- ▶ 刷题模式：显示答案 → 自评（会了 / 模糊 / 不会）→ 自动下一题，支持乱序
- ⭐ 错题本：自动收集"不会"的题，可一键重刷
- 📖 背诵考点：各章高频考点整理（黑马逆袭宝典）
- 💻 进度保存在浏览器本地（localStorage），无需登录
