# 咨询工程师《现代咨询方法与实务》刷题站

2026 年咨询工程师考试备考网站，按章节整理题库，支持在线刷题与背诵。手机 / 电脑自适应布局。

**在线访问：https://a2393439531.github.io/consult-quiz/**

## 功能

- 📚 11 个章节题库（约 1050 题），每题含参考答案与解析
- 📝 20 套题卷：历年真题（2021/2022/2023/2025）+ 机构模拟冲刺卷
- ▶ 刷题模式：显示答案 → 自评（会了 / 模糊 / 不会）→ 自动下一题，支持乱序、只刷错题
- 📄 原题图表：题干引用表格 / 图形的题目，可查看原 PDF 页面图片；5 道公式图片答案已补齐（共 179 页）
- ⭐ 错题本：自动收集"不会"的题，按来源分组，可一键重刷
- 📖 背诵考点：各章高频考点整理（69 个）
- 🔍 按题源筛选、关键词搜索
- 💻 电脑端：刷题页左右双栏（左案例背景 / 右答题），列表多列排布
- 📱 手机端：单列自适应，底部标签导航
- 💾 进度保存在浏览器本地（localStorage），无需登录；同浏览器多标签自动同步
- 🔁 续刷：保存本轮队列、位置及评分，刷新后可继续或重新开始
- 📅 今日待复习：不会、模糊、会了分别在最近评分后的 1、3、7 天进入复习；另有模糊题入口
- 📦 首页支持 JSON 进度导出、导入；导入时验证题目及记录，重复评分保留较新的记录
- 🔗 1508 条收录对应 1387 道独立题目；提问与答案均一致的重复题共享评分，原章节和试卷入口保留

## 本地运行、构建和检查

在本仓库目录（`site/`）运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8765`。请通过 HTTP 运行，直接双击 HTML 无法可靠加载题库。

构建工具已纳入本仓库的 `tools/`；工作区外旧 `build/` 脚本作为历史版本保留，后续使用以下统一入口：

```powershell
# 根据已有题库归一化、检查，并发布到本地 data/ 和 pages/
python tools/build.py

# 从已提取文本和原始 PDF 完整重建
python -m pip install -r tools/requirements.txt
Copy-Item tools/config.example.json tools/config.local.json
# 将 config.local.json 的三个目录改成自己的实际绝对路径
python tools/build.py --reparse

# 只检查，不修改数据
python tools/quality.py
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/app.test.cjs
```

PDF 提取辅助脚本为 `tools/convert2.py`，可通过 `QUIZ_PDF_DIR` 和 `QUIZ_TEXT2_DIR` 指定输入、输出；已有提取文本可直接用于重建。`config.local.json` 与 PDF 文本缓存不纳入 Git。离线检查与测试只需 Python 标准库和 Node.js，完整重建另需 PyMuPDF。

构建先在同盘临时目录执行基础解析、增量合并、图表匹配、公式答案补页和身份归一化。字段、索引数量、全局 ID、图片引用及原有题目保留检查通过后才替换本地输出；替换失败会回滚。`reports/validation.json` 记录检查结果，`reports/duplicates.json` 列出重复组。只有问题、背景及答案一致的记录合并身份；答案不同的记录保持独立供人工核对。

旧的 `cctp2026_progress_v1` 记录会按身份映射读取，下一次成功保存或导入时写入统一 ID，较新的评分优先。题库版本变化会使旧练习队列失效，已保存评分仍然保留。只保存最近一轮练习队列。

首页仅请求索引，进入章节或复习列表时再加载题目。加载失败可重试；保存失败不会自动进入下一题。复习列表按独立题目去重，章节与试卷仍保留原收录数量，因此各章节数量相加可能超过首页独立题目总数。

代码与数据检查已配置在 `.github/workflows/check.yml`。发布仍使用原 GitHub Pages 配置；本地构建不会自动提交或推送。
